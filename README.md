# 电商用户行为数据分析项目
基于 Python 模拟生成的 5000 条电商用户行为数据，独立完成从数据清洗到业务建议的全流程分析。

## 项目技术栈
Python，pandas数据清洗，matplotlib可视化
Excel（数据透视表、VLOOKUP)

## 文件说明
- analysis.py：完整项目源代码
- cleaned_data.csv：清洗完成数据集
- chart1_品类销售额.png: 各品类销售额对比
- chart2_转化漏斗.png: 用户行为转化漏斗
- chart3_时段活跃.png: 分时段用户活跃分布
- 电商用户行为数据分析报告.docx：完整分析报告

## 项目流程
1.利用Python模拟生成原始电商数据
2. 数据清洗：去重、剔除Unknown、处理缺失,输出表格
3. 统计：品类销售额、用户转化漏斗、时段活跃度
4. 绘图输出图表，撰写完整分析报告

##核心发现
1.  Home与Clothing品类贡献主要营收，建议重点运营
2. 整体浏览-购买转化率为28.9%，加购-购买转化率为48.2%
3.晚间19-22点为用户活跃高峰，建议集中投放营销资源
